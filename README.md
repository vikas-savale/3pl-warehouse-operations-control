# 3PL Warehouse Operations & Dispatch Control System

An Excel and Power BI based operational control and analysis project for a fictional 3PL warehouse environment.
The project focuses on warehouse order fulfillment, dispatch readiness and operational exception analysis.

## Business Scenario

Northridge Industrial Products uses Avenmark Logistics for warehouse operations.

The warehouse process covers:

- Inbound receiving
- Inventory handling
- Customer orders
- Allocation
- Picking
- Vehicle assignment
- Loading
- Dispatch

## Technology Stack

- Microsoft Excel
- Power Query
- Excel formulas
- VBA
- Power BI
- DAX
- Python
- Git and GitHub

## Project Objective

The system is designed to support warehouse operations by providing visibility into dispatch readiness, operational exceptions and fulfillment workload.
